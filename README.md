# 📚 Biblioteca da Guilda

Projeto desenvolvido para centralizar e facilitar o acesso aos materiais utilizados pela Guilda SensorWeb.

A proposta é criar uma biblioteca digital onde os membros da equipe possam encontrar, consultar e compartilhar materiais relacionados aos processos, ferramentas, treinamentos e conhecimentos utilizados no dia a dia.

## 🚀 Objetivo

Centralizar em um único lugar conteúdos como:

* 📄 Documentações
* 🎓 Treinamentos
* 📚 Materiais de estudo
* 🎥 Vídeos
* 🔧 Procedimentos técnicos
* 💡 Guias e tutoriais
* 📌 Informações úteis para a equipe

## 🛠️ Tecnologias

## 💻 Como executar o projeto

### 1. Clonar o repositório

```bash
git clone https://github.com/chico-sw/Biblioteca-da-Guilda-.git
```

### 2. Entrar na pasta

```bash
cd Biblioteca-da-Guilda-
```

### 3. Instalar as dependências

```bash
npm install
```

### 4. Iniciar o projeto

```bash
npm run dev
```

Após iniciar, o Vite disponibilizará o projeto localmente no endereço indicado pelo terminal.
